## How to read the current draft
Click Releases above and download the PDF. No software needed.

## How to add a reference
Join the Zotero group `ELL305-TermPaper` (invite is in your email), install the
Zotero Connector browser extension, and click its icon on any paper you want
cited. It reaches our bibliography automatically. No Git, no LaTeX needed.
